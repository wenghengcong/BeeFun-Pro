# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately by email:

- `wenghengcong@icloud.com`

Please avoid opening a public issue for vulnerabilities until a fix is available.

## What to Include

- Affected version/commit
- Reproduction steps or proof of concept
- Potential impact
- Suggested mitigation (if available)

## Response Targets

- Initial acknowledgement: within 7 days
- Triage/update: as soon as practical based on severity and maintainer availability
