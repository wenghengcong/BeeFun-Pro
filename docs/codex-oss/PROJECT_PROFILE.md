# BeeFun Pro - Project Profile (for Codex for OSS)

## Project Summary

BeeFun Pro is an open-source iOS GitHub client that helps developers discover repositories, follow notifications, and review project/user details from mobile devices.

## Current Status

- Phase: Active development with real users
- Age: The repository was created in 2015 and continues to receive updates
- Core language: Swift
- License: BSD-4-Clause

## Primary Users

- Individual developers and student developers
- Open-source maintainers who need on-the-go monitoring
- Users who want a native iOS GitHub browsing/management workflow

## Problem It Solves

- Desktop-first GitHub workflows are often heavy for quick checks
- Existing mobile clients are either inactive or too limited
- BeeFun Pro provides a native, efficient, and readable workflow for daily open-source participation
